# Procedures

Código-fonte de stored procedures para versionamento. Manter aqui o script completo, mas nunca executar `CREATE` ou `ALTER` sem autorização explícita do usuário.

As decisões entre tabelas temporárias, CTEs e outras estratégias, inspiradas no fluxo de `SP_ANALISE_FERTMINAS`, estão definidas no `AGENTS.md` deste diretório.
